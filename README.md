# Prof. Raphael Z. Sangeda — academic website

Static academic website prepared for GitHub Pages.

## Publish at `sangeda.github.io`

Published at <https://sangeda.github.io> from the repository's `main` branch.

The site uses plain HTML, CSS and JavaScript, with no build step.

## MUHAS Publications Observatory

The observatory at `/muhas-publications/` is generated by
`scripts/build_muhas_observatory.py`. It queries the MUHAS OpenAlex institution
lineage (`I154840374`, ROR `027pr6c67`), preserves an immutable raw snapshot,
and exports publications and authorships as CSV, Excel and SQLite.

The `Build MUHAS Publications Observatory` workflow supports manual provisional
runs and automatically creates final snapshots just after every MUHAS fiscal
quarter closes (Q1 Jul–Sep, Q2 Oct–Dec, Q3 Jan–Mar, Q4 Apr–Jun). Dated files are
archived in a GitHub Release; the current files are deployed with the website.
