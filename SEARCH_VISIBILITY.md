# Search visibility

Public canonical pages:
- https://sangeda.github.io/
- https://sangeda.github.io/publications.html
- https://sangeda.github.io/muhas-publications/
- https://sangeda.github.io/dcepd-courses/

`scripts/build_site_seo.py` maintains descriptive titles, descriptions, canonical
URLs, social metadata, JSON-LD entities, crawlable navigation and sitemap/robots.
The profile explicitly identifies Raphael Zozimus Sangeda and his research,
leadership and mentorship. Course cards are present in HTML before JavaScript.
The Observatory also has a static annual-count table for crawlers and readers.
Scheduled generators and deployment staging reapply metadata after rebuilding.

In Google Search Console, select the verified https://sangeda.github.io/ property,
submit `sitemap.xml`, and request indexing for these four URLs using URL Inspection.
The existing Google verification HTML file remains unchanged.
Indexing and rankings are decided by search engines, not guaranteed by this code.

Historical-course workbook: a fixed 19 September 2026 export, with 27 explicit
No records and 75 blank-flag records on separate tabs. It contains professional
course/director/unit information and recorded dates only. It does not refresh
with the public-catalogue API job and is clearly labelled as a dated snapshot.
