Definitions and reporting limits

One course may have several Runs. Attendance is summed only where a non-negative whole number is recorded. Blank or invalid values remain unknown; an explicit zero remains zero. These data do not establish completion or the number of unique people trained.

Past Run dates describe recorded delivery activity; they do not independently prove that a session took place. Future-dated Runs are separated. Runs without a valid start date remain in an Unknown period. Financial figures, applicant identities, contact information and application documents are excluded.

The source systems are being refined. Missing reporting and unmatched course selections are retained for review. The dashboard does not enforce registry or application rules or write back to either project.

A geographical map will require a verified boundary dataset; the ranked region tables provide the current location view without inventing coordinates.
